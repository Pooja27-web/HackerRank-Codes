Problem: Set Union
==================

You are given two sets.
Set A = {1,2,3,4,5,6}
Set B = {2,3,4,5,6,7,8}

How many elements are present in A ∪ B?

Only enter the correct integer in the editor below. Do not include any extra spaces, tabs or newlines.

Answer: 8

Explanation:
A ∪ B = {1,2,3,4,5,6,7,8}
Total unique elements = 8
